
# Student Result Calculator

## About the Project
A beginner-friendly JavaScript project that calculates a student's total marks, percentage, and average across five subjects.

## Features
- Takes student name as input.
- Takes marks for five subjects.
- Calculates total marks.
- Calculates percentage.
- Calculates average marks.
- Displays the complete result in the browser console.

## Technologies Used
- HTML5
- JavaScript

## JavaScript Concepts Practiced
- Variables (let and const)
- Strings and Numbers
- Type Conversion
- Arithmetic Operators
- Math Methods
- Template Literals
- Console Output

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Enter student information and marks.
5. Check the browser console for results.
