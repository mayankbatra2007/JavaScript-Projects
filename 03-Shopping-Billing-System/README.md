# 🛒 Mini Shopping & Billing System

A beginner-level JavaScript project that simulates a basic shopping and billing system. The project demonstrates how JavaScript fundamentals can be used to manage product information, maintain shopping cart data, calculate prices, apply discounts, and generate a final shopping bill.

## 🎯 Project Objective

The main objective is to apply fundamental JavaScript concepts to solve a real-world problem.

The system will maintain product details, calculate individual product costs, determine the subtotal, calculate discounts, and generate the final payable amount.

## ✨ Project Features

- **Product Management:** Store product IDs, names, and prices.
- **Product Catalog:** Maintain a collection of available products.
- **Shopping Cart:** Store selected products and their quantities.
- **Price Calculation:** Calculate the total price of individual products.
- **Subtotal Calculation:** Calculate the total shopping amount.
- **Discount Calculation:** Calculate discount amounts.
- **Final Bill Generation:** Generate a formatted shopping receipt.
- **Shopping Summary:** Display total items, subtotal, discount, and final amount.
- **Purchase Date:** Display the date and time of the bill.

## 🧠 JavaScript Concepts Used

This project strictly uses the following JavaScript fundamentals:

| Topic | Application |
|---|---|
| Variables | Store product prices, quantities, and totals |
| Datatypes | Work with strings, numbers, and booleans |
| Strings | Format product details and billing receipts |
| Maths | Perform price, subtotal, and discount calculations |
| Date and Time | Generate purchase date and time |
| Functions | Organize billing operations into reusable functions |
| Arrays | Store product collections and shopping cart data |
| Objects | Represent products and shopping cart items |
| Memory | Understand variable, object, and array storage |
| Setting Up | Organize and execute the JavaScript project |

## 🛠️ Technology Stack

## 📌 Project Scope

This is a fundamental-level JavaScript project.

The initial version focuses exclusively on the JavaScript topics listed above. It will use predefined product and cart data to practise data representation and calculations.

Advanced JavaScript concepts, DOM manipulation, APIs, databases, and external libraries are outside the scope of this version.

## 🚀 Learning Outcome

By completing this project, you will gain practical experience in:

- Representing real-world entities using JavaScript objects.
- Managing collections using arrays.
- Organizing logic using functions.
- Performing mathematical calculations.
- Working with strings and dates.
- Combining multiple JavaScript fundamentals into one practical application.
