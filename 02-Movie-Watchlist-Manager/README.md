# 🎬 Movie Watchlist Manager

## 📌 About the Project

Movie Watchlist Manager is a beginner-friendly JavaScript project that allows users to manage their personal movie watchlist.

Users can display their saved movies, search for a movie, add new movies, and remove movies from their watchlist.

This project is created to practise JavaScript fundamentals through practical implementation.

## ✨ Features

- Display all movies in the watchlist.
- Search for a specific movie.
- Add new movies to the watchlist.
- Remove movies from the watchlist.
- Display the total number of movies.

## 🛠️ Technologies Used

- JavaScript (ES6+)

## 📚 JavaScript Concepts Practiced

- Variables (`let`, `const`)
- Arrays
- Strings
- Array Methods (`push()`, `includes()`, `indexOf()`, `splice()`)
- String Methods (`toLowerCase()`, `trim()`)
- Template Literals
- Console Output

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run `script.js` using Node.js.
4. Follow the instructions to manage your movie watchlist.
